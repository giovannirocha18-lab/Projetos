# Gerador-de-Riquezas
Site vaiprocarrinho.com.br

## Em construção
- `index.html`: página "Em breve", que é o que o público vê.
- `previa.html`: a loja de verdade, para testar em https://vaiprocarrinho.com.br/previa (ou vaiprocarrinho.pages.dev/previa).
- Todas as páginas pedem aos buscadores para não aparecer no Google (arquivo `_headers` e tag `robots`).

## Para lançar o site
1. Apagar `index.html` e renomear `previa.html` para `index.html`.
2. Apagar o arquivo `_headers` e a linha `<meta name="robots" ...>` do novo `index.html`.
